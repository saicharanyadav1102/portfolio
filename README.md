# KV Saicharan Yadav — Developer [Portfolio](https://portfolio-saicharan-23.vercel.app/)

A personal developer portfolio built with **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**. Designed with a clean editorial aesthetic, responsive layout, and highly interactive components.

---

## ✨ Features & Highlights

- **Modern & Responsive:** Fully responsive layout built with utility-first Tailwind CSS.
- **Dark / Light Theme:** Switch between clean light mode and high-contrast dark mode with automatic `localStorage` saving.
- **Interactive UI Components:** 
  - Dynamic **Infinite Scrolling Marquee** for technical skills.
  - Hover-activated **3D Tilt Cards** with tactile popups and color-coded gradient tracing.
  - Interactive **Project Filtering System** (Full-Stack, Data Analytics, Cloud, UI Design).
  - Persistent **Spotlight Quote Card** with session-based like counter.
- **Live Contact Form:** Real-time email delivery using [Web3Forms](https://web3forms.com/) with a clean confirmation popup.
